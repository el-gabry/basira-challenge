# Competition Baseline Gap Analysis

This document records capability gaps observed before implementing
competition-period innovations.

## Existing strong baseline

The imported system already has:

- religious disciplines;
- reasoning modes;
- evidence obligations;
- answer constraints;
- deterministic evidence decisions;
- retrieval sufficiency;
- source usage policy;
- structured claims;
- literal claim/source integrity;
- Quran quote verification;
- Quran cross-source orthography integrity;
- governed retrieval components.

These are baseline capabilities, not competition innovations.

## Competition deltas

### G1 — Official content sensitivity A/B/C/D

The audited religious reasoning contract does not expose the official
competition A/B/C/D content sensitivity model as a first-class routing
contract.

### G2 — Official Source Eligibility Gate

Existing source usage policy is useful, but competition behavior needs
an explicit eligibility decision tied to the official scientific
reference and governed artifact identity.

### G3 — Witness-aware Quran attestation

Existing Quran integrity is already strong on exact text and
orthographic equivalence.

Competition work should extend witness identity explicitly before
comparison, including riwaya / rawi / rasm / dabt / edition metadata,
rather than rebuilding the current verifier.

### G4 — Semantic claim/evidence verification

The existing claim integrity layer validates structural/literal
relationships.

Competition Trust Shield must separately evaluate semantic support.

### G5 — False-consensus guard

The existing reasoning contracts already contain disagreement
constraints.

Competition work must make false-consensus detection observable,
testable and measurable end-to-end.

### G6 — Failure certification

The baseline has deterministic evidence decisions but no typed
competition failure certificate separating:

- confirmed system error;
- legitimate scholarly disagreement;
- insufficient evidence;
- context dependence;
- source conflict;
- expert review.

### G7 — Pluralism-safe learning

No competition-period repair/protected-disagreement memory and
counterfactual promotion loop exists yet.

This is a primary innovation target.
